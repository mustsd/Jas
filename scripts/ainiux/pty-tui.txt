# The full-screen interface on a real terminal, with no `--tui` flag: it is what a
# terminal gets by default, and this scenario is what asserts that.
#
# It exercises the parts a pipe cannot reach at all -- the panes, the help overlay
# and its scrolling, the `:` prompt on the bottom row -- and then leaves, so the
# harness can check that the alternate screen and the cursor were handed back.
#
# 100 columns and 30 rows: wide enough for both panes side by side, tall enough for
# the message area and the key reminder.
#
# Driven by `bash scripts/ainiux/check` as a regression check.
